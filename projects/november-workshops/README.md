# Additional LangChain workshops

These newly supplied workshop PDFs are archived as source material. Their complete classroom programs remain in the PDFs; this repository does not yet provide checked standalone implementations for these projects.

| Workshop | Main idea | Source |
| --- | --- | --- |
| LangChain mega revision (workshop 5) | Modules 1–8 and practice programs | [PDF](../../sources/pdfs/workshop5-%20LC%20revision.pdf) |
| Beat the Excuse Monster (workshop 6) | A goal and motivation game using LCEL and conversation history | [PDF](../../sources/pdfs/workshop6%20-%20beat%20the%20excuse.pdf) |
| AI PDF quiz generator (workshop 7) | Load and split a text PDF, generate questions, save a text file | [PDF](../../sources/pdfs/workshop7%20-%20LC%20PDF%20Generator.pdf) |
| Company policy assistant | RAG with PDF loading, embeddings, and in-memory cosine ranking | [PDF](../../sources/pdfs/workshop%20-%20AI%20powered%20assistant%20-%20RAG.pdf) |

The original files `lc workshop.pdf` and `Lanchcain workshop.pdf` are byte-for-byte duplicates of workshops 5 and 6 respectively. This page records that relationship while keeping one archived copy of each.
